Engineering approach

How I work, with the project where each habit showed up.

Compare against a baseline

In the Qwen study every metric is reported for the untouched base model, LoRA, and QLoRA under the same prompts and test split.

Distrust surprising results

Base, LoRA, and QLoRA first produced nearly identical outputs. The cause was an evaluation bug, not failed training. I rebuilt the evaluation with isolated adapters and self-tests.

Keep training and inference consistent

In EuroSAT, a single frozen normalization file is used by both the training code and the app, so deployed inputs match what the model saw in training.

Separate behavior from knowledge

Fine-tuning made answers concise and on-style, but the models still produced plausible wrong facts. That is why the next stage is retrieval.
